# CADE30008 Zensical theme

The Bristol Flight Lab Zensical theme with the Flight Lab mark taken out of
the header's edge artwork, used by the CADE30008 site. The slanted edge stays;
the roundel, bird, aircraft and wordmark do not. See BRAND.md.

Consumed as the `theme/` submodule of the course repository, which points
`custom_dir` at `theme/dist`.
